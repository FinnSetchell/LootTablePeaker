# LootTablePeaker

A server-side Fabric dev tool for Minecraft 1.21.10 that prevents opening loot containers and displays their loot table keys via a title screen.

![Loot Table Peeker Screenshot](https://pub-24a4e0e7ea8544a5b6f73c3a23512589.r2.dev/images/c689a5812b4748249468b955a1aeac84.png)

## Commands
- `/lootpeek` - shows current state (ON or OFF)
- `/lootpeek on` - enables peek mode server-wide
- `/lootpeek off` - disables peek mode server-wide

*(Requires OP level 2)*
